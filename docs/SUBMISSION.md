## Доступ комиссии

PIN раздела для родителей в демо-профиле — **1234** (указан в README и на экране входа). В обычном профиле PIN задаёт сам проверяющий при первом запуске.

## Что сделать перед сдачей

1. Проверить релизный APK на **физическом устройстве** с ОЗУ от 3 ГБ (ТЗ 3.1) по тест-кейсам из раздела 10 документации. Заполнить таблицу 10.3 и пересобрать DOCX:

   ```bash
   python tool/build_docs.py
   ```

2. Указать в разделе 12 документации, чем созданы иллюстрации и анимации и на каких условиях их можно использовать.
3. Записать резервное видео (до 3 минут) по сценарию ниже.
4. Слить финальную ветку в `main`, поставить тег и запушить его:

   ```bash
   git tag -a v1.0.0 -m "Финальная сдача 1.0.0 (сборка 1)"
   ```

   ```bash
   git push origin v1.0.0
   ```

5. Открыть экспертам доступ к репозиторию, APK, презентации и видео и проверить все ссылки из окна инкогнито.
6. **Сохранить ключ подписи.** Без него нельзя выпускать обновления с тем же именем пакета. Ключ и `key.properties` лежат вне git; сделайте их резервную копию в надёжном месте и не публикуйте.

## Сценарий живой демонстрации и видео (Приложение А)

Хронометраж — около 3 минут. На финале сборка показывается вживую; видео — запасной вариант на случай сбоя.

| Время | Шаг ТЗ | Что показать | Что сказать |
|---|---|---|---|
| 0:00 | 1 | Установленное приложение, запуск, знакомство с Рыжиком | «Цель игры — научиться распоряжаться монетами: потратить на важное, на приятное или отложить» |
| 0:15 | 2 | PIN взрослого, игровое имя и возраст — без телефона и e-mail | «Регистрации нет, данные только на устройстве» |
| 0:30 | 3 | Профиль → цвет худи и аксессуар; имя Рыжика в разделе для взрослого | «Можно собрать больше 9 вариантов внешнего вида» |
| 0:45 | 4 | Главный экран: баланс, копилка, цель, задание дня | |
| 0:55 | 5 | Бюджет: распределить монеты по трём направлениям, подтвердить | «Нельзя распределить больше, чем есть» |
| 1:10 | 6 | Задание на карте: верный ответ, затем ошибка и объяснение | «Объяснение показывается при любом ответе» |
| 1:30 | 7 | Магазин: корм (важное), игрушка (приятное), попытка купить при нехватке | «Не хватает N монет — предлагаем варианты, в минус уйти нельзя» |
| 1:50 | 8 | Цели: выбрать цель, положить в копилку | |
| 2:00 | 9–10 | Демо: «Панель демо» → «Завершить день» → итоги и очки роста → следующий день; смена стадии Рыжика | «Рыжик растёт по итогам решений за несколько дней» |
| 2:25 | — | День 2: звонок мошенника → «Позову взрослого» | «Учим не сообщать коды из СМС» |
| 2:40 | 11 | Закрыть приложение и открыть снова — прогресс на месте | |
| 2:50 | 12 | Раздел для взрослого (в демо PIN **1234**) → прогресс, темы → «Начать демо заново» / в обычном профиле «Удалить профиль» | «Сброс доступен взрослому без разработчика» |

Советы по записи: `adb shell screenrecord /sdcard/demo.mp4` (до 3 минут) или запись экрана на телефоне; перед записью включить демо-режим и начать демо заново.
