# Рыжик — скрипты утверждённых анимаций (уровни 1–3)

Каждая анимация рендерится из одной картинки лиса (без видео-генератора): скрипт деформирует
исходный PNG по слоям (тело, голова, уши, хвост), рисует веки/моргание, жевание, еду и сердечки.
Выход: кадры 960×960 PNG с альфой, 60 fps → MP4 на белом фоне + WebM с альфой.
Первый и последний кадр каждой разовой анимации совпадают с базовой (idle) позой пиксель в пиксель.

## Установка
```
pip install -r requirements.txt      # numpy, opencv-python, pillow, scipy
# ffmpeg нужен только для сборки видео (render.sh)
```

## Запуск
```
./render.sh <уровень> <имя> <скрипт> [ПЕРЕМЕННАЯ=значение]
./render.sh level2 L2_feed_happy_treats anim_feed_items.py ITEM=treats
./render_all.sh                      # все 30 роликов
```
Результат в `renders/`: папка кадров `<имя>/f0000.png…`, `<имя>_60fps.mp4`, `<имя>_alpha.webm`.
Быстрая проверка отдельных кадров: `cd level2 && ONLY=0,100,200 ITEM=treats python3 anim_feed_items.py /tmp/test`.

## Утверждённые анимации и чем они делаются

Одинаково на всех уровнях (в своей папке `levelN/`):

| Анимация | Скрипт | Параметр | Кадров |
|---|---|---|---|
| Довольный — базовая (цикл) | `anim_happy.py` | — | 298 |
| Грустный/голодный — базовая (цикл) | `anim.py` | — | 300 |
| Гладят довольного (сердечки) | `anim_pet7.py` | — | 210 |
| Гладят грустного | `anim_pethungry.py` | — | 210 |
| Довольный ест из миски | `anim_feed_v4.py` | — | 306 |
| Довольный ест угощения (яблоко, морковь, косточка) | `anim_feed_items.py` | `ITEM=treats` | 306 |
| Довольный ест кекс | `anim_feed_items.py` | `ITEM=cupcake` | 306 |
| Грустный ест угощения → становится довольным | `anim_feed_h2h.py` | `ITEM=treats` | 306 |
| Грустный ест десерт → становится довольным | `anim_feed_h2h.py` | `ITEM=cupcake` | 306 |
| Грустный ест из миски → становится довольным | `anim_feed_h2h.py` | `ITEM=bowl` | 306 |

Какие именно версии были утверждены (по переписке):

- **Уровень 1** (маленький Рыжик): hungry idle v3, happy idle v4, pet happy hearts v2, pet hungry v4,
  feed happy **v4** (миска; v5 была отклонена в пользу v4), feed treats v2, feed cupcake v2,
  hungry→happy v6 (угощения), treat_dessert, basic_bowl.
- **Уровень 2**: happy idle v2, hungry idle v3 (веки без тёмных пятен), pet happy (с исправленными веками),
  pet hungry, feed happy bowl, feed happy treats/cupcake (последняя версия: тело наклоняется целиком,
  лапы и ноги неподвижны, без двойных ног и второй худи), hungry→happy treats/dessert/bowl (без линии на хвосте).
- **Уровень 3** (повзрослевший Рыжик): все 10 анимаций в той версии, что была отправлена последней.

## Состав папок
- `fox_happy.png`, `fox_hungry.png` — исходники лиса. Для уровней 2 и 3 это ваши картинки, выровненные
  (только масштаб/поворот/сдвиг) под кадр уровня 1; оригиналы лежат в `originals/`.
- `fox_petting_love.png` — картинка с сердечками, из неё берутся спрайты сердец.
- `food_bowl.png`, `food_treats.png`, `food_cupcake.png` — еда.
- `tracks.npy`, `open.npy` — кривые движения базовой анимации (сняты с референсного видео).
- `eyemasks*.npy` — контуры глаз для век. На уровне 3: `eyemasks*.npy` — для базовых анимаций,
  `eyemasks*_ext.npy` — для поглаживания и кормления (веки дополнительно закрывают ресницы у уголков).
- `morphlib.py` — морфинг грустной морды в довольную.
- Уровень 2: `anim_feed_items_for_h2h.py` — состояние скрипта кормления, на котором были утверждены ролики
  «грустный → довольный» (его подключает `anim_feed_h2h.py`); `anim_feed_items.py` — финальная версия для
  «довольный ест угощения/кекс».

## Проверка
Все скрипты из этого архива прогнаны заново и сравнены с утверждёнными роликами:
уровни 2 и 3 совпадают пиксель в пиксель, уровень 1 совпадает с точностью сжатия видео.
Одно исключение: на уровне 2 в роликах «грустный → довольный» в последние ~0.5 с (глаза закрыты,
морда меняется на довольную) веки чуть другого оттенка — позже в скрипт довольного лиса было внесено
исправление цвета век (то же, что в утверждённых «гладят довольного» и «довольный ест»),
и эти ролики его подхватывают.
